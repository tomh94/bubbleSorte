Bubble sort

Bubble sort porovnává vždy dvojici sousedních prvků a prohodí je, pokud jsou v nesprávném pořadí. Po každém průchodu polem se tak na svém konečném místě usadí další (největší dosud neseřazený) prvek.

porovnávají se prohazují se na svém místě 
pro i = 0 ... n-2
  pro j = 0 ... n-i-2
    pokud a[j] > a[j+1]
      prohoď a[j] a a[j+1]

i = – j = –
